# Low-cost IP protection baseline

## Status

This is operational information, not legal advice. Rules differ by jurisdiction, ownership facts, publication history, employment relationships, and the type of material involved.

## Free measures available now

1. Preserve the private/public boundary. Keep Core32 bodies, unpublished methods, personal context, internal sources, and commercially sensitive implementation outside the public repository. Trade-secret protection depends on information having value from not being generally known and on reasonable efforts to keep it secret.
2. Maintain copyright notices. Copyright arises automatically when eligible original expression is fixed; registration is not required for copyright to exist.
3. Apply clear standard licenses. This repository now distinguishes PolyForm-covered software, CC-covered narrative documentation, reserved marks, third-party rights, and undistributed material.
4. Preserve provenance. Keep `PROVENANCE.md`, reviewed source history, exact authorship records, and later a signed initial commit and signed release tag. Publish SHA-256 checksums with releases. These are evidence practices, not substitutes for registration.
5. Use the mark consistently. Use `Agentic Knowledge OS TM` only as an unregistered source identifier, reserve matching repository and domain names where practical, and do not use the registered symbol unless registration is actually obtained.
6. Control contributions. Do not merge outside contributions until an agreement preserves the rights required for noncommercial and separate commercial licensing.

## Lowest-cost formal step

The U.S. Copyright Office currently lists an electronic filing fee of $45 for a single author who is also the claimant, for one work not made for hire, when that application is eligible. The standard electronic application is $65. Registration is optional for copyright to exist, but for U.S. works registration or refusal is needed before enforcing exclusive rights through litigation, and timely registration may provide additional remedies and evidentiary benefits.

For a cohesive initial software release owned by the same claimant, ask the Copyright Office or qualified counsel whether the program and bundled documentation can be registered together. The Office's computer-program guidance says this can sometimes be done when ownership and publication conditions are satisfied.

Official resources:

- https://www.copyright.gov/what-is-copyright/
- https://www.copyright.gov/about/fees.html
- https://www.copyright.gov/circs/circ61.pdf

## Patent checkpoint—not the default cheap route

If a genuinely novel technical invention may be present, pause public disclosure for patent advice. The USPTO currently lists a provisional application filing fee of $65 for a qualifying micro entity, $130 for a small entity, and $325 otherwise. A provisional filing is not an issued patent, and a thin self-filed description may fail to support later claims. Attorney and later nonprovisional costs can be much larger.

Official fee schedule: https://www.uspto.gov/learning-and-resources/fees-and-payment/uspto-fee-schedule

## Practical order

1. Keep the GitHub repository private.
2. Complete the public-file and ownership audit.
3. Decide whether any withheld invention needs patent review before disclosure.
4. Create a reviewed and preferably signed initial commit.
5. Push privately and inspect the GitHub-rendered license and inventory.
6. Register the cohesive initial release with the Copyright Office if the expected value justifies the $45 or $65 filing fee.
7. Only then make the repository public and publish the alpha release.

The zero-dollar baseline is meaningful but limited: source separation protects retained secrets, copyright protects eligible expression automatically, licensing defines permissions, and Git preserves evidence. None creates exclusive rights over an abstract agentic operating method.

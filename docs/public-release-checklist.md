## Release sequence

Initial release sequence:

1. create `hearthandcode/agentic-knowledge-os` as an empty repository — human-reported complete;
2. create one reviewed initial commit locally;
3. push the reviewed `main` branch to the configured remote;
4. inspect GitHub-rendered files, repository metadata, license detection, and file inventory;
5. change visibility to public only after that inspection;
6. publish an initial prerelease such as `v0.3.0-alpha.1`, not a production release;
7. replace announcement placeholders with the observed public release URL.

Repository creation, commit, and initial push were authorized for this release pass. Visibility change, prerelease publication, and community announcement remain separate effects requiring separate confirmation.

## Public-claim checks

- use `source-available`, not `open-source`, if a noncommercial restriction is selected;
- call this an early design or alpha candidate;
- state that host adapters are source-level and live compatibility remains unverified;
